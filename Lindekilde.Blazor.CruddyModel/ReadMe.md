# CruddyModel

## About
A simple ASP.NET Blazor component that could do CRUD operations 
on any database table using a model class or record. 

## Key Features
- CruddyModel requires a model class or record
- Uses DataAnnotations (if any) for validation when editing or creating
- CruddyModel uses Dapper - not Entity Framework

## How to Use
See CruddyModelDemo project for examples of how to use the CruddyModel component:
https://github.com/JakobLindekilde/CruddyModel

## Cruddy - The version that does not require a model class or record
